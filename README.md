# 🎯 Résolution du Google XSS Game — Laboratoire de Sécurité Web

Ce projet présente l'analyse technique et l'exploitation méthodique des vulnérabilités **Cross-Site Scripting (XSS)** à travers la résolution complète du challenge interactif **Google XSS Game**.

---

## 📌 Objectifs & Contexte
- **Module :** Sécurité des Applications Web / Réseaux et Cybersécurité
- **Statut :** Terminé avec succès (6/6 Niveaux)
- **Compétences validées :** Identification des failles XSS Reflected, Stored et DOM-based, injection de payloads JavaScript, analyse du code source web et contournement des filtres de sécurité.

---

## 🛠️ Niveaux Résolus & Concepts Clés

| Niveau | Type de Vulnérabilité / Concept |
| :--- | :--- |
| **Level 1** | Reflected XSS (Injection simple de balise `<script>`) |
| **Level 2** | Stored XSS (Persistance via formulaire/commentaire) |
| **Level 3** | DOM-based XSS (Manipulation de l'URL/hash et attributs d'images) |
| **Level 4** | XSS contextuel dans un bloc JavaScript (Injecting into JS context) |
| **Level 5** | Injection via attributs d'événements (`onload`, `onerror`) et redirections |
| **Level 6** | Contournement de regex et chargement de scripts externes malveillants |
